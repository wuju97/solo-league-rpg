AI MEMORY UPDATE #3 — paste into Settings → AI Memory → Instructions
(these are mechanics/rules, not world content), appended to what's
already there. Covers what's changed since the last update.

CLASS LOCKING (new):
- A player's class becomes permanent the moment they enter their
  first political hierarchy fight (Warriors through Champion,
  solo or as part of a party). Primordial fights and creature
  fights do not trigger this lock — only real hierarchy fights do.

TRADING (new — Duel Trade tab):
- Genuine peer-to-peer gifting, separate from duel wagers. A player
  can offer any combination of gold, AP, any number of owned items
  (weapons/armor/consumables), and any number of owned ability
  cards to another player by gamer name. The recipient can Accept
  (everything genuinely transfers) or Reject. Trading a card moves
  it from sender to recipient entirely — it isn't duplicated.

DUEL WAGERING (fixed, now fully working):
- Both players in a duel can lock in a bet during Prep — gold, AP,
  and/or specific items — which gets escrowed (removed from their
  character/inventory immediately upon locking). When the duel
  ends, the winner receives the combined pot from both sides. A
  real Cancel Duel option exists in Prep that refunds any locked
  bet if either player needs to back out before the fight starts.

TRAVELER MINI-GAMES (new — World Map, Travel the Roads):
- Three Wordle-style guessing games a traveler may offer instead of
  a fight: PKMN (real Pokemon — compares Type 1, Type 2,
  Generation, Category), NRTO (real Naruto characters — compares
  Village, Clan, Rank, Chakra Nature), LOL (real League champions —
  compares Region, Role, Damage Type, and Release Year with a
  higher/lower indicator). All three share one underlying system:
  a hidden target is picked (excluding a player's last 15 answers
  per game, so repeats are genuinely rare), guesses are checked
  attribute-by-attribute, and a real autocomplete/substring-search
  box prevents blind spelling guesses. Solving pays gold, same
  range as any other traveler favor.

AMBIENT MUSIC (new):
- A single default background track plays automatically, but only
  on the World Map page, and only after the player clicks the "I
  solemnly swear I'm up to something" button covering the map on
  arrival. It plays on loop, continues uninterrupted through
  anything clicked within World Map, and always restarts from the
  beginning whenever the player arrives at World Map from any other
  page. Players can replace it with their own track, mute it, or
  adjust its volume in Settings — none of that changes the
  World-Map-only default behavior.

Anything in prior AI Memory notes suggesting class can be freely
changed at any time, or that Duel Trade only supports duel
challenges without real wagering or trading, is now OUTDATED.
