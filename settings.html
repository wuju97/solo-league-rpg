AI Memory

This is the default knowledge base for any AI feature added later — shared site-wide, same for every player, since it describes the one world and site everyone uses. Edited here, not per-account.

Type 1 — the world's actual content: lore, kingdoms, characters, items, anything that exists. Seeded with a starting summary; add anything you want the AI to know.

Type 2 — how things actually work: the website's systems, and the rules governing how the world functions (not what's in it).

Type 3 — the website itself: what every tab, feature, and button actually does. For answering questions about how to use the site, not about the world.

Content Tools

Not player-facing — a private tool for drafting new content in your established style. Uses your own Gemini key, grounded in AI Memory.

API

Your own API keys, stored on your account only — no one else, including other players, can read these. Only the last 4 characters are ever shown once saved.

A Development key (the free one you get instantly) expires every 24 hours and needs manual regeneration from the Riot Developer Portal — auto-sync will quietly stop working until you paste in a fresh one. A Personal key doesn't expire but requires applying to Riot first.

No option for India — Riot has never launched a dedicated India server. Indian players typically play on EUW/EUNE or through Garena-based access depending on account setup; pick whichever your account actually plays on.

Once both are set, use the "Sync Latest Match" button on the KDA / XP page — it checks for a new match while that page is open, no manual typing needed.

Reset

This permanently wipes all of your progression, inventory, discoveries, achievements, and history — your class, rank, level, gold, gear, cards, kingdom unlocks, hierarchy defeats, everything. Your account, gamer name, and API keys are not affected. After resetting, you'll need to pick a class again before you can fight anything.

This cannot be undone.
