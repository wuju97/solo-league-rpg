# ECONOMY / ITEM & LOOT RULES

(Rarity tiers, equipment types, and artifact categories are Type 1 — intentionally
visible to players in World Lore → Legendary Artifacts. This file covers the
underlying mechanics, which should just be true of how the system behaves.)

## Discovery Philosophy
Legendary items are never random loot. They're earned through multi-stage
questlines, ancient ruins, political alliances, world events, kingdom reputation,
crafting with impossible materials, and solving long-running mysteries. No player
should ever accidentally find the world's greatest weapon in an ordinary chest.

## Legendary Weapons
81 total exist (9 per kingdom), each fully hidden in the database until a player
actually earns it through gameplay — already implemented via the World Secrets/
Artifacts discovery system.

## Ancient Artifacts
Over 300 exist, left behind by the Ancients (gravity engines, weather prisms, memory
crystals, etc). Most no longer function completely — players should gradually learn
how to restore them through play, not be told how upfront.

## Relic Sets
Some items belong to sets (e.g. an "Explorer's Legacy" set of five pieces).
Collecting an entire set should unlock a hidden questline, not just grant a flat stat
bonus.

## Cursed Artifacts
Not every powerful item is purely beneficial — a sword might grow stronger while
slowly lowering NPC trust, a ring might boost magic but cause nightmares, a crown
might grant leadership bonuses while attracting assassins. Power should always come
with a meaningful trade-off.

## Living Artifacts
A handful of relics possess awareness — they reject unworthy wielders, react to
important places, remember previous owners, unlock new abilities as trust grows, and
occasionally influence dialogue or quests. Players build a relationship with these
rather than simply equipping them.

## The Artifact Chronicle
Every artifact should carry its own historical record — who forged it, who wielded
it, when it was lost, who eventually rediscovers it (which player, and when). The
world should remember who found it and how its story evolves.

## Reputation Discounts (already implemented in Shop)
Citizen normal price, Trusted -5%, Hero -10%, Champion -15%, Legend -20%. Same tiers
as Reputation.md.
